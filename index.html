User instructions

How the team should use the board and task logic

Board instructions

AUTO means no staff action is needed. Legalboards handles that step quietly in the background, like a very organized little robot with no interest in creating more meetings.

HAND OFF means let Legalboards move the matter only after the required task logic is completed.

Treat Setup Complete — Ready for Filing as the intake clearance point. That means the matter is clean enough to hand off safely.

Once county routing happens, the intake card should no longer be the active place for work.

Task instructions

The Workflow is Alive. That means no staff action is needed. Legalboards knows what to do.

Attorney tasks are the legal judgment points. Paralegal tasks are the operational and file integrity points.

If the information is not in a Clio Custom Field, it is not considered actionable for moving the case forward.

Any information that needs explanation, context, or manual clarification should be added to Clio Notes.

Client information should not live only in your mind. Legalboards is smart, but sadly not psychic.

Pinpoint 1

Before sending anything, paralegals should always review the auto generated Welcome Letter and Questionnaire for merge field accuracy, especially attorney name, staff name, county, and case number.

Pinpoint 2

When a task says notes, use notes. Bankruptcy, support details, and other non field items belong in Clio matter notes, not in made up custom fields that will only confuse the file later.

Pinpoint 3

Ready for Filing means something real. Once a matter reaches that stage, the intake work is complete, routing checks are cleared, and the file is safe to hand into the county workflow.

Pinpoint 4

Delete only what the instruction tells you to delete. If a task says to delete when not applicable, that applies only to that branch task, not to the rest of intake logic.
